提供使用固定测试汇率的汇率换算器。

== Description ==

注册 [market_currency_converter] Shortcode 和只读 REST API：
/wp-json/market-calculator/v1/currency-rates

当前版本的数据仅用于功能演示和开发测试，不代表真实市场价格。

== Installation ==

启用插件后会以幂等方式创建“汇率换算器”页面。
